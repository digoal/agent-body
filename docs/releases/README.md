## 版本编号规则

- **Major (X.0.0)**: 架构级变更，接口不兼容
- **Minor (0.X.0)**: 新功能模块，向后兼容
- **Patch (0.0.X)**: Bug 修复、性能优化、文档改进

## 如何添加新版本

1. 在本目录创建 `vX.Y.Z.md`
2. 更新本 `README.md` 表格
3. 在 Git 打 tag: `git tag -a vX.Y.Z -m "Release vX.Y.Z"`
4. 更新 `Cargo.toml` 中的 `version`
