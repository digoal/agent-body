## 🎯 这个版本做了什么

从零开始搭建了 Agent Body 的 Rust 工程骨架，完成了四大核心模块的首版实现与测试闭环。这是一个能编译、能跑、能测的完整起点。

## ✨ 新增功能

### 配置管理 (`src/config/`)
- 实现 `config.toml` 配置文件自动发现与解析
- 支持 XDG 标准路径与 `AGENT_BODY_CONFIG` 环境变量覆盖
- 内置白名单/黑名单路径配置、扫描深度、监听目录等核心参数

### 存储层 (`src/storage/`)
- 嵌入式 SQLite 3（rusqlite bundled）自动建库建表
- Schema 自动迁移机制：首次运行自动初始化 `assets`、`changes`、`memories` 等核心表
- 支持资产 CRUD、变更追踪、记忆读写

### 放置建议引擎 (`src/placement/`)
- 基于目录约定的放置建议规则引擎
- 路径冲突检测与安全脱敏（自动过滤密钥、凭证等敏感路径）
- 命名约定校验（kebab-case / snake_case）

### 扫描引擎 (`src/scanner/`)
- 白名单目录深度遍历、黑名单目录仅止于当层（绝不下钻）
- 资产自动发现与元数据提取

### 环境感知 (`src/env/`)
- `/proc` 进程列表采集
- 硬件规格探测（CPU、内存、磁盘）

### CLI 主入口 (`src/main.rs`)
- Clap derive 解析，支持 `scan`、`env`、`memory`、`placement` 子命令

## 📦 技术栈
- Rust 1.99.0 + Tokio + Clap 4.5 + rusqlite 0.31 (bundled + FTS5) + chrono + uuid + serde
