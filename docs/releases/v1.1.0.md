# Agent Body v1.1.0 Release Notes (`2026-11-27`)

> **一句话总结**：从 `v1.0.0 GA` 演进为「真世界自我证伪（Shadow A/B `H1~H5`） × 弱向量 Know-How 网络 & Omni-RRF × 纯 Rust 多模态 L1A × 全端 1:1:1 大一统」的 `v1.1.0` 生产版本。

---

## 核心新增能力（Phase 58 ~ Phase 64）

1. **三态运行模式、MCP 减税档位与 `ShadowAbEngine` `H1~H5` 自愈（Phase 58 / 63）**
   - 支持 `body_only` / `bypass` / `shadow_ab` 三态运行模式，并支持 `~/.agent-body/{runtime_mode,execution_mode}.override` 热覆盖（CLI/MCP/AGY/Claude/Hermes 全桥接一致生效）。
   - 支持 `mcp_profile = full (43) | core (10) | dev (18) | ops (20)` Schema 上下文减税。
   - `ShadowAbEngine` 识别 `H1_RECALL_MISS` ~ `H5_LEASE_MISLEAD`，自动执行 `H1`/`H2` 写穿自愈并返回零回退合流结果。
2. **Know-How 知识网络与 Omni-RRF 8 维融合检索（Phase 61 ~ 62）**
   - Heading-Aware 章节切片 + 行业术语别名归一 + PMI 共现图 + `qwen3.5:0.8b`（`think=false`）原文锚定因果/边界三元组抽取。
   - 整合加权 BM25（含驼峰拆词）、纯 Rust Fuzzy、可选向量、索引下沉定向 1~2 跳图扩展、层级、文档互链及标量调制（`matched_channels` + `reasoning_paths`）。
3. **纯 Rust 多模态 L1A 解析与三通道魔数统一分类（Phase 59 / 63）**
   - [`src/scanner/multimodal_ext/mod.rs`](../../src/scanner/multimodal_ext/mod.rs) 提供零第三方依赖的 HTML、Parquet Thrift Compact Footer、CSV/TSV 列类型与行数估计、JSONL 键集合、MP3/FLAC/OGG 音频头解析；`ffprobe`/`pdfinfo`/`pdftotext`/`unzip` 统一收口为有界 `500ms` 超时子进程（`kill + wait`）。
   - `Scanner` / `FileWatcher` / `AutoSyncEngine` 三大通道共用 `classify_asset_path`，统一写入 `schema_version = "2.0"` 与 `mime_type`；新增多谓词 `kv_filter` 与无损 `backfill_multimodal_assets`。
4. **跨平台 100% 全绿、Web UI 1:1:1 与 Benchmark `v3.9`（Phase 60 / 62 / 64）**
   - 升级评测套件至 **Benchmark `v3.9`**：`W1~W19` + `M1~M6` + `DQ1~DQ10` + `COMP-C1~C4` + `PR-01~14`。
   - Web UI（默认 `http://127.0.0.1:8765`）补齐三态运行模式/Shadow A/B 实测面板、资产 `kv_filter`/`modality`/`asset_type`/`backfill_multimodal` 交互与 `LaunchAgent` macOS 托管指南。

5. **跨平台 CI/CD、`<1000L` 模块治理、全仓命名大一统与 SSoT 防漂移闭环（Phase 65 ~ Phase 68）**
   - **可信度量与跨平台**：`DQ2` / `DQ6` / `HomeostasisVitalsEngine` 修复大边数截断与 `exact_id` 标识符精确召回；`preflight` / `daemon` / `Makefile` 原生支持 macOS（`FSEvents` / `LaunchAgent` / `libproc`）与 Linux，并落地 Ubuntu + macOS 双平台 `.github/workflows/{ci,release}.yml`。
   - **模块治水与零静默吞错**：拆分全仓 10 个 `>=1000L` 生产文件至 `<1000L`（[`src/api/mcp_tools/mod.rs`](../../src/api/mcp_tools/mod.rs)、[`src/benchmark/workloads/mod.rs`](../../src/benchmark/workloads/mod.rs)、[`src/scanner/multimodal_ext/mod.rs`](../../src/scanner/multimodal_ext/mod.rs) 等），收紧 `code_hygiene.py` 至 `>1000L = 0`、`let _ =` `0 / 15`、全仓零旧命名残留。
   - **一等公民 SSoT 对齐**：[`scripts/evolution_manifest.py`](../../scripts/evolution_manifest.py) 强制校验 `Cargo.toml (1.1.0)` 版本对齐、活跃文档/Skill 反引号源码路径 0 断链、`parity_api` 43 路由精确命中 `server.rs`，4 套演说生成器（`presentation/*.html`）动态读取架构快照彻底消除指标漂移。

6. **共享 SPI 契约、微内核 + 10 周边扩展与三大精简发行版（Phase 69 ~ 73 · ISSUE #51, #52）**
   - **存储 SPI 契约与预防性拆分**：完成 Top-5 高水位模块 `<700L` 拆分，并新增 [tests/storage_spi_contract.rs](../../tests/storage_spi_contract.rs) 验证 SQLite 与 DuckDB 12 域 `StorageProvider` 等价语义。
   - **纯机制微内核与周边插件化**：构建 [kernel/](../../kernel/body-sdk/src/lib.rs)（`body-sdk` / `body-protocol` / `body-kernel`，8 张 `body_cat_*` 目录表 + 7 Hook + 6 Routine + 轨 B 沙盒）与 10 个 [contrib/](../../contrib/) 标准五件套扩展（含 Linux/JVM/Nginx、PG/达梦/金仓、mTLS/RLS、合规脱敏、SIEM、轨 B CMDB 工单、`obs_telemetry`），组装发布 `agent-body-kernel-minimal` (`3.9M`)、`agent-body-probe` (`6.7M`) 与 `agent-body-dba` (`6.4M`) 三款零 C++/零 DuckDB 精简二进制。

7. **全栈工业级可观测闭环与一等公民大一统（Phase 74 ~ 75 · ISSUE #53, #54）**
   - 修复内核 `trace_id` 断链，落地 `ObservabilityProvider` / `KernelStatsRegistry` / `InFlightRegistry` / `SlowOpRing`；新增 `contrib/obs_telemetry`（Prometheus 0.0.4、W3C `traceparent`、JSONL、`OBS-01~05` 自诊断）；旗舰版落地 `GET /metrics`、`agent-body body metrics`、`body_state(action="metrics")`、`AGENT_BODY_LOG_FORMAT=json` 与全一等公民交叉防漂移门禁。
