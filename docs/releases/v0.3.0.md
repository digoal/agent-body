## 🎯 这个版本做了什么

Agent 本体从"能通信"进化到"能自治"——完成了 CodeGraph 宏微联邦联动、宿主系统实装部署（systemd 常驻守护）、自治生态（拓扑自愈 / 规则自演化 / 宿主 GC / 记忆时序仲裁 / TUI 实时看板），以及完整的用户手册与投资人 Deck。

## ✨ 新增功能

### CodeGraph 宏微联邦联动 (`src/links/`)
- `CodeGraphBridge`：宏观文件级依赖图 + 微观符号级 CodeGraph 双层联邦联动
- 断链审计 (`body_links_audit`)：检测失效引用、推演修复候选
- 爆炸半径可视化 (`body_links_impact`)：Mermaid 依赖图自动生成
- 链路修复器 (`body_links_repair`)：基于 Levenshtein 相似度 + 代码指纹自动推演 patch

### 宿主自治生态 (Phase 7)
- **拓扑自愈** (`src/links/`)：依赖链断裂时自动生成修复建议
- **规则自演化** (`src/placement/`)：`PlacementLearner` 基于历史资产与变更聚类自学习沉淀新放置规范
- **宿主 GC** (`src/env/`)：`HostGarbageCollector` 安全白名单清理 `/root/new/tmp/` 超期孤儿文件、僵尸进程诊断
- **记忆生命周期仲裁** (`src/memory/`)：`MemoryLifecycleManager` 时间半衰期衰减 + 对立语义认知矛盾自动仲裁
- **TUI 实时看板** (`src/tui/`)：交互式终端单屏看板，实时展示资产、进程、记忆、链路健康状态

### 宿主系统实装
- Systemd Unit 文件：`agent-body.service` enable + start 长驻守护
- Release 二进制安装到 `/usr/local/bin/agent-body`
- inotify 文件实时监听 + 动态进程定时采集 + 后台自主深度巡查
