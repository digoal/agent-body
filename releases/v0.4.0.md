## 一、版本里程碑总览（Phase 13 ~ Phase 26）

v0.4.0 标志着 Agent Host Steward 从“单机工具底座”全面进化为**面向 AI Agent 的系统级认知中枢**：

1. **Web UI 2.0 与「☀️ 白天蓝图 / 🌙 夜间深空」双主题系统（Phase 13, 19, 25）**
   - 单二进制内嵌 Tokio 异步 HTTP/SSE 引擎（零外部 Node.js/CDN 依赖）；
   - 五大工作台（事实拓扑、协作锁、Hook 事件流、OLAP 分析、路演剧场）与实时 Canvas 拓扑联动；
   - 彻底清除硬编码暗色值，建立语义 CSS Token 体系，支持 `T` 键一键切换昼夜主题。
2. **HOOK 驱动集成引擎与生态防爆路由（Phase 14, 16）**
   - `EventBus` 事件总线、`AutoSyncEngine` 全自动回写、Antigravity/Cursor/Claude/Git 客户端 Hook 生成器；
   - `McpConfigScanner`、`SkillCatalogScanner`（120+ 技能目录）与 `ContextBudgetRouter` 按 Token 预算 Top-K 路由，防止 Context 被打爆。
3. **零 Panic 硬化、跨平台探针与轻量多机联邦 Mesh（Phase 15, 17, 18）**
   - 生产代码 **0 处** `unwrap()`/`expect()` 门禁（`make lint-panic`）；
   - Wait-For Graph 死锁环路检测与等待队列唤醒（`steward_lock_wait` / `steward_lock_deadlock_check`）；
   - `PlatformProbe`（Linux/macOS/Windows）与 HTTP Peer Mesh 跨节点查询/锁路由（`steward_mesh_query`）。
4. **黑白屏 100% Parity 对齐与路演故事化演示剧场（Phase 21, 22, 25）**
   - **39 个原生 MCP 工具**、CLI 子命令与 Web REST API 保持 **1:1:1** 双向同步（`/api/v1/parity/matrix` 守护）；
   - 内建 6 大黄金剧目真引擎沙盒推演（`steward_demo_scenario`），三层故事化舞台与 ROI 实时账单。
5. **三层正交元数据体系与 Ollama 异步双轨标注（Phase 23）**
   - L1 Rust 微秒级确定性语法提取 + L2 本地 Ollama 小模型（`qwen3.5:0.8b`）脱敏异步精炼，配合 Micro / Standard / Full 三级渐进披露，彻底告别空洞元数据。
6. **「比较优势」思想起源与「地层剖面 / 工程蓝图」双 HTML 演说（Phase 24）**
   - 16 页路演版（`presentation.html`）与 22 页演讲版（`steward-deck.html`）单文件零依赖内联 SVG + 联动讲稿，Playwright 渲染自检全绿。
7. **数据治理硬化与真实依赖图谱全链路闭环（Phase 26）**
   - `PolicyMatcher` 黑名单目录与子项双向阻断、`restricted` 受限深度入口过滤、`NoiseFilter` 与 `FileWatcher` 确定性去噪；
   - `LinksEngine::refresh_links_for_asset` 全链路接入扫描与变更流水线，幂等构建宿主机真实依赖拓扑；
   - `build.rs` Git 指纹监听与 `status` 全量精确计数修复，现网库净化重扫零逃逸、零幽灵。
