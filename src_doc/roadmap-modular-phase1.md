## 一、阶段目标与范围

构建 Agent 在宿主机物理世界中的“透视眼”，让 Agent 彻底告别对物理环境的盲人状态。本阶段聚焦四大核心事实资产的构建与只读问答接口的暴露：

```
┌─────────────────────────────────────────────────────────────────────────────┐
│               Phase 1: 宿主机事实图谱核心 (Host Reality Graph)              │
├─────────────────────────────────────────────────────────────────────────────┤
│  [1.1] 工具能力语义注解库 (Capability Graph) ◄─── (当前第一步)              │
│        • 内置 100+ 常用 Linux 工具语义标签与最佳用法 (如 pdftotext -layout) │
│        • 扫描 $PATH 与本地已安装二进制，绑定物理路径与真实版本             │
│        • 支持自然语言意图意图匹配 ("处理 PDF 提取排版文字" -> pdftotext)    │
│  [1.2] 内核级进程与网络端口无噪拓扑 (/proc & Ports)                         │
│        • 微秒级解析 /proc 与套接字，端口占用反查 (PID/命令/Cwd/运行时间)   │
│        • 智能过滤内核底层底噪，提供事前端口防撞与孤儿诊断                  │
│  [1.3] 系统自动化拓扑网络 (Systemd & Cron Topology)                         │
│        • systemd 服务与配置依赖解析 (改动 config 会影响谁)                 │
│        • crontab 定时偷跑任务排查 (何时跑/跑什么脚本/输出到何处)           │
│  [1.4] 源码工程与本地资料库编目 (Code & Knowledge Catalog)                  │
│        • 自动感知 Git 仓库与 CodeGraph 就绪状态 (引导使用 codegraph)        │
│        • 编目 /root/new/note/ 权威网站清单与本地离线技术资料                │
│  [1.5] 统一只读查询语义接口与 CLI/MCP 端点 (Read-Only API)                  │
│        • 实现 steward_fact_query 与 CLI 子命令                              │
│        • 严格只读契约，集成端到端测试与真实场景验证                        │
└─────────────────────────────────────────────────────────────────────────────┘
```
