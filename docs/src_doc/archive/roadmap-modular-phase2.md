## 一、阶段目标与范围

回答 **"How to ACT"**（应该怎样行动、放置与规约）。即使 Agent 掌握了机器上的一切事实，如果缺乏对用户习惯的默契，依然会乱丢文件、乱起名字、触碰安全红线。

本阶段聚焦三大核心能力落地：
1. **放置引擎 2.0**：支持基准物理路径建议、项目级配置覆盖（`.agent-body-rules.toml`）、意图模糊打分与命名规范强校验；
2. **工程习惯与安全门禁**：首选工具链引导（CodeGraph 优先）、数据权威真实性门禁、北京时区统一与脱敏保护；
3. **纠偏自演化学习**：监控用户对 Agent 产生文件的移动/重命名操作，自动归纳沉淀新规则，让Agent 本体越用越懂主人。
