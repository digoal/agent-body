## 🎯 这个版本做了什么

对齐用户在 README.md ISSUE #10 提出的关键要求：**“考虑到开发环境和实际使用可能存在一定的差异，运行依赖要写清楚，防止到其他环境使用时部署失败。必须体现在代码层面、配置层面、文档层面、相关的SKILL层面。”**

本版本完成了“四层贯通”的运行依赖显式化与可移植部署体系升级：

1. **代码层面**:
   - 新增 `src/preflight/` 运行时依赖诊断引擎，分为 **REQUIRED (必选/阻断)**、**OPTIONAL (可选/优雅降级)**、**INFO (环境信息)** 三级；
   - 守护进程 `daemon` 启动序列内置 preflight 检查，阻断不可用环境并输出排障建议；
   - 新增 `agent-steward preflight` CLI 子命令，支持表格化与 `--json` 格式输出；
   - 新增 `build.rs`，在编译期将 Git Commit Hash、UTC 构建时间、目标 OS/架构静态注入二进制；
   - `src/config/` 新增严格校验逻辑（端口范围校验、向量维度校验、存储后端依赖联动检查）。

2. **配置层面**:
   - 项目根目录新增带详尽中英文注释的配置文件参考模板 `config.example.toml`，详述每个参数的作用、默认值、取值范围与依赖前提。

3. **文档层面**:
   - 新增一站式部署指南 `INSTALL.md`：
     - 系统与运行依赖全景矩阵（Linux procfs、C++ runtime libstdc++6、CMake、Ollama、PostgreSQL 等）；
     - Debian/Ubuntu、RHEL/CentOS、Alpine Linux、Arch Linux 四大发行版安装命令；
     - 常见部署故障与排障速查表 (FAQ)；
   - 重构 `src_doc/development.md`，更新至 v0.3.2 完整架构全景、依赖清单与命令矩阵；
   - 更新根目录 `README.md` 指向 `INSTALL.md`。

4. **容器化与工程脚本**:
   - 新增工业级多阶段构建 `Dockerfile` 与 `.dockerignore`；
   - 新增容器化参考编排 `docker-compose.yml`（配置 `--pid host` 与 `/proc` 挂载）；
   - 新增 `Makefile`，集成 `make build`、`make check`、`make test`、`make preflight`、`make install`。

5. **SKILL 技能层面**:
   - 全面刷新项目内置的三套技能（`agent-steward-guide`、`agent-steward-developer`、`agent-steward-doc-writer`）；
   - 工具数统一刷新为 31 个，测试数对齐为 140 项；
   - 在开发规范中确立铁律：**“新增外部依赖或环境假设时，必须同步在 INSTALL.md 声明并在 src/preflight/mod.rs 中增加预检探针”**。

## 📦 交付文件一览

- `src/preflight/mod.rs`: 依赖预检引擎
- `build.rs`: 构建期环境注入
- `config.example.toml`: 详注配置模板
- `INSTALL.md`: 部署手册与环境矩阵
- `Dockerfile`: 多阶段容器构建
- `docker-compose.yml`: 容器编排
- `Makefile`: 自动化工作流
- `.dockerignore`: 镜像过滤规则
- `src_doc/development.md`: 全面升级的开发者指南
- `skills/agent-steward-*/SKILL.md`: 三套技能刷新
