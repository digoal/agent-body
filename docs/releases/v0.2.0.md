## 🎯 这个版本做了什么

大管家从"能跑"进化到"能通信"——实现了 MCP Server、实时文件系统监听、依赖链爆炸半径分析、以及 FTS5 + Ollama 向量 RRF 混合检索。Agent 第一次能通过标准 MCP 协议与大管家对话了。

## ✨ 新增功能

### MCP Server (`src/api/`)
- 实现 JSON-RPC 2.0 MCP Server 通信层
- 首批注册 **14 个原生 MCP 工具端点**：
  - `steward_brief` / `steward_placement_suggest` / `steward_placement_rules`
  - `steward_asset_search` / `steward_asset_register` / `steward_asset_scan`
  - `steward_env_processes` / `steward_env_show`
  - `steward_memory_add` / `steward_memory_search`
  - `steward_links_query` / `steward_changes_since`
  - `steward_port_check` / `steward_session_close`

### 文件系统 Watcher (`src/watcher/`)
- 基于 inotify 的实时文件变更监听
- 防抖机制（500ms 合并连续写入事件）
- 变更自动入库 `changes` 表

### Daemon 后台守护 (`src/daemon/`)
- 长驻后台进程模式
- 整合 Watcher + 定时任务调度

### 依赖链引擎 (`src/links/`)
- 文件间引用关系自动发现
- 反向依赖爆炸半径分析（`steward_links_query`）
- 变更影响范围推演

### 记忆混合检索 (`src/memory/`)
- FTS5 全文检索 + Ollama BGE-M3 向量嵌入
- RRF (Reciprocal Rank Fusion) 双路融合排序
- 记忆相关度评分与 Top-K 返回

### 环境感知增强 (`src/env/`)
- 端口冲突检测与可用端口推荐（`steward_port_check`）

### 会话生命周期 (`src/session/`)
- Agent 会话创建与清理
- 临时资源自动回收（`steward_session_close`）

### Glob 匹配器 (`src/scanner/matcher.rs`)
- 高性能 Glob 模式匹配，支撑白名单/黑名单路径过滤

## 🔧 改进
- 存储层扩展：新增 `links` 表、`port_checks` 表
- CLI 新增 `daemon`、`links` 子命令
